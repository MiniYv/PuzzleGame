# 世界解谜之旅

解谜副本、跑图探索、排行榜签到，双货币背包系统。

## 命令

| 命令 | 说明 |
|---|---|
| /谜题 /puzzle | 查看帮助和开始游戏 |
| /签到 | 每日签到领金币 |
| /副本 | 挑战解谜副本 |
| /答 | 回答副本谜题 |
| /跑图 | 探索世界地图 |
| /地图 | 查看地图信息 |
| /排行 | 查看排行榜 |
| /背包 | 查看道具 |
| /商店 | 购买道具 |
| /使用 <道具> | 使用道具 |
| /改名 <昵称> | 设置昵称 |
| /我的 | 查看个人信息 |

## 系统

- 双货币：金币 + 钻石
- 副本：挑战谜题获取奖励
- 跑图：探索地图收集资源
- 排行榜：与其他玩家比拼
- 背包：道具管理与使用

## 安装

```bash
loyan plugins install MiniYv/PuzzleGame
```
